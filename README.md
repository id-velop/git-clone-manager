# Quick Clone

Quickly clone GitHub and GitLab repositories with one click—no terminal needed.

## Features

- One-click cloning from repository pages
- Supports GitHub and GitLab
- Choose a local destination folder
- HTTPS cloning with no protocol setup
- Optional terminal launch after cloning
- Runs locally through Chrome Native Messaging

## Setup

Requirements: Google Chrome on macOS or Windows.

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode** and choose **Load unpacked**.
3. Select the `chrome-extension` folder.
4. Open Quick Clone and follow the three setup steps. The provided command configures the local companion automatically.

## Usage

Open a GitHub or GitLab repository, click **Quick Clone**, choose a folder, and start cloning.

## Development

Edit files in `chrome-extension/` or `native-host/`, then reload the extension in Chrome.
