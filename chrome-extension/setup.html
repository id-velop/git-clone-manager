macOS setup

Get ready to clone

Your repositories.
On your Mac.

The extension needs a small local companion to select folders and run Git. Install it once, then return to the extension.

  1. One command. You're set.

    Open Terminal, paste this command, and press Return. It downloads and installs the companion for this extension automatically.

    Loading your extension ID…

    Requires macOS, Node.js and Git. No administrator password needed.

    Don't have Node.js or Git?

    Install the macOS LTS version from Node.js. To install Git, run xcode-select --install in Terminal and follow the macOS prompts. Then reopen Terminal and run the command above.

    What does this command install?

    It downloads the companion from our GitHub repository, copies it into your user Library, and registers it for this extension. It does not install or update the browser extension.

    View the installer source ↗

  2. Return to the extension

    Open Clone to Folder from the Chrome toolbar and click Reconnect. When it says Connected, you're ready to clone.

    If your extension ID changes, copy and run the command again.
