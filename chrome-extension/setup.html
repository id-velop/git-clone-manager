Clone to Folder
macOS setup

Get ready to clone

Your repositories.
On your Mac.

The extension needs a small local companion to select folders and run Git. Install it once, then return to the extension.

  1. One command. You're set.

    Open Terminal, paste this command, and press Return. It checks your Mac, installs any missing tools, and sets up the companion.

    Loading your extension ID…

    macOS only. First-time setup may take several minutes. Follow any password or confirmation prompts in Terminal.

    What gets installed?

    Existing Node.js and Git installations are reused. If either is missing, the command installs it using Homebrew, setting up Homebrew first if needed. macOS may request an administrator password or Command Line Tools.

    Then it downloads the companion into your user Library and registers it for this extension. It does not install or update the browser extension.

    View the installer source ↗

  2. Return to the extension

    Open Clone to Folder from the Chrome toolbar and click Reconnect. When it says Connected, you're ready to clone.

    If your extension ID changes, copy and run the command again.
