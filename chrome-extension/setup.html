Clone to Folder
macOS setup

Get ready to clone

Your repositories.
On your Mac.

The extension needs a small local companion to select folders and run Git. Install it once, then return to the extension.

  1. Download the companion source

    Download the project ZIP from GitHub, then double-click it to extract. Keep the extracted folder until setup is complete.

    Download for macOS ↗

    Requires Node.js and Git. The installer checks both before making changes.

    Don't have Node.js or Git?

    Install the macOS LTS version from Node.js. To install Git, run xcode-select --install in Terminal and follow the macOS prompts. Then reopen Terminal and continue below.

  2. Open Terminal in the extracted folder

    Open Terminal, type cd with a trailing space, drag the extracted folder into the window, then press Return.

    Copy and run this command. It registers the companion for this specific extension.

    Loading your extension ID…

    What does the installer do?

    It copies the companion into your user Library and registers a Chrome Native Messaging host. It does not install or update the browser extension.

  3. Return to the extension

    Open Clone to Folder from the Chrome toolbar and click Reconnect. When it says Connected, you're ready to clone.

    If you change the extension ID or reinstall it under a different ID, run step 2 again.
